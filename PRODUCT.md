# Oppy — Product Context

**What:** A zero-config, CLI-first tool that scrapes, filters, dedupes and tracks **paid remote internships** and **cash-prize hackathons** from Unstop, Devpost, RemoteOK and WeWorkRemotely (+ custom RSS). Caches to local SQLite (WAL, URL-unique dedup), exports a links-enabled Markdown dashboard to Obsidian. Distributed via npm (`@dshenoyh/oppy-cli`) and PyPI (`oppy-cli`). MIT.

**Register:** Brand / landing page (design IS the product for this surface).

**Audience:** Now — developers & CS students who live in the terminal. Later — a hosted web UI for non-technical opportunity-hunters (teased on the page, not built yet).

**Concept spine:** *Oppy is a scouting satellite.* It orbits the job boards, sweeps them continuously, and beams filtered signal (paid + remote only) down to your terminal and notes. Every section is art-directed around this: radar sweep, orbital rings, signal pings, telemetry readouts.

**Primary conversion goal:** Copy the `npx @dshenoyh/oppy-cli` command / land on GitHub. Secondary: waitlist interest in the coming web app.
