// pre-flight checks

      
Questions before launch

    


    

      

        
          Is it actually free?
          +
        
        
Yes — MIT licensed, published to npm and PyPI, no account, no API key, no rate-limited free tier. It runs on your machine and costs you nothing but disk space.

      


      

        
          Where does my data go?
          +
        
        
Nowhere. Listings are written to a local SQLite database (~/.config/oppy/opportunities.db) and a Markdown file in your vault. There is no Oppy server, no telemetry and no sign-in — the only network calls are to the public job boards themselves.

      


      

        
          Do I need to know Python?
          +
        
        
No. You need Python 3.8+ installed — most machines already have it — and Oppy verifies and installs its own dependencies on first run. If you can run npx, you can run Oppy.

      


      

        
          Will I see the same listing twice?
          +
        
        
No. The cache holds a unique index on the opportunity URL, so re-running the sweep only ever adds what is genuinely new. Run it hourly if you like — the ledger stays clean.

      


      

        
          I don't use Obsidian. Does it still work?
          +
        
        
Yes. If the default vault path is missing, the export falls back to Opportunities.md in your working directory — or point OPPY_EXPORT_PATH anywhere you like. It is plain Markdown; every notes app reads it.

      


      

        
          Can I add my own sources?
          +
        
        
Point the custom RSS scraper at any feed and it joins the sweep alongside the four built-in platforms. New platform scrapers are welcome as pull requests — see CONTRIBUTING.md in the repo.
